## 📚 Statistics Learning Roadmap

### Foundation of Linear Algebra

- Scalars, vectors, matrices, and tensors
- Matrix addition and subtraction
- Scalar multiplication and Hadamard product
- Matrix dot product and transpose
- Determinant and inverse of a matrix

### Foundation of Probability

- Permutations and combinations
- Introduction to probability and probability rules
- Independent and dependent events
- Conditional probability
- Bayes' theorem

### Descriptive Statistics

- Introduction to statistics
- Descriptive versus inferential statistics
- Measures of central tendency: mean, median, and mode
- Measures of dispersion: mean absolute deviation (MAD), variance, and standard deviation
- Percentiles, quartiles, interquartile range (IQR), and five-number summary
- Covariance and correlation
- Pearson correlation and Spearman correlation
- Cosine similarity

### Probability Distributions

- Introduction to probability distributions
- Bernoulli, binomial, and Poisson distributions
- Uniform distribution
- Gaussian/normal distribution and its importance in data science
- Properties, mean, and variance of the normal distribution
- Empirical rule
- Standard normal distribution and Z-score
- Skewness and kurtosis
- Log-normal distribution

### Inferential Statistics

- Sampling techniques
- Central Limit Theorem (CLT)
- Introduction to hypothesis testing
- Null and alternative hypotheses
- Type I and Type II errors
- Critical value, significance level, and p-value
- One-tailed and two-tailed tests
- One-sample, two-sample, and paired t-tests
- F-test
- One-way and two-way ANOVA
- Chi-square test

## ✅ Learning Expectations

- Attend classes and practice sessions consistently.

- Work through manual calculations before using library functions.
- Write and run every Python example yourself.
- Choose statistical measures and tests based on the question, data, and assumptions.
- Interpret results using clear sentences and relevant units.
- Complete assignments and revise previous topics alongside the current lesson.
- Ask questions with your calculation, code, input, and error message ready.
- Apply assessment and mock interview feedback to your next practice session.

## 🐍 Suggested Tools for Practice

- **Python:** Step-by-step calculations and problem solving.
- **NumPy:** Vectors, matrices, and numerical calculations.

- **Matplotlib / Seaborn:** Visualising distributions and relationships.

- **Jupyter Notebook / Google Colab:** Running examples, recording observations, and practising interactively.

## 🎯 By the End of the Module

You should be able to:

- Perform basic vector and matrix operations.
- Solve probability problems using counting rules, conditional probability, and Bayes' theorem.
- Summarise data using central tendency, dispersion, and position.
- Explain covariance, Pearson correlation, Spearman correlation, and cosine similarity.
- Recognise common probability distributions and select suitable examples for each.
- Interpret skewness, kurtosis, Z-scores, and the empirical rule.
- Explain sampling techniques and the Central Limit Theorem.
- Formulate null and alternative hypotheses.
- Interpret significance levels, p-values, and Type I and Type II errors.
- Select and apply introductory t-tests, F-tests, ANOVA, and chi-square tests while checking their assumptions.
- Use Python to calculate statistics, visualise data, and communicate findings.
- Build the statistical foundation needed for data analysis and machine learning.
